# Homebrew Tap for cschuman

Custom Homebrew formulae.

## Installation

```bash
brew tap cschuman/tap
```

## Available Formulae

### goperf

Preventive performance analysis for Go - catch O(n²) loops and N+1 queries before production.

```bash
brew install cschuman/tap/goperf
```

Or:

```bash
brew tap cschuman/tap
brew install goperf
```

## Updating

```bash
brew update
brew upgrade goperf
```
